# K-M Paint Unmixer

A Kubelka–Munk spectral recipe solver for Golden Heavy Body acrylic paints.
Enter any target sRGB colour (hex, eyedropper, uploaded image) and the solver
returns a pigment mixture that reproduces it, honouring a user-chosen cap on
how many paints may appear in the recipe.

## How it works

- **Data source**: Golden's measured reflectance for 78 HB paints (10-mil
  drawdowns over a white Leneta card, 400–700 nm at 10 nm, D65 / CIE 1964 10°
  observer). Titanium & Zinc White are absent from the dataset, so they are
  synthesized from Scott Allen Burns' measured TiO₂ acrylic curve, fitted to
  Golden's published thin-film CIELAB for each white
  (see [`constants.ts`](constants.ts), regenerated by
  [`generate_constants.py`](generate_constants.py)).
- **Optics**: measured R → Saunderson-corrected internal reflectance
  (k1 = 0.03, k2 = 0.6) → `K/S = (1−R)²/2R` → mix → invert →
  re-apply Saunderson.
- **Mixing law** (selectable in the UI):
  - *K-M calibrated* (default): γ-calibrated Kubelka–Munk targeting
    **fully-opaque appearance** — one scalar γ per pigment is fitted so that
    100% of a paint reproduces Golden's measured "6mm Fully Opaque" CIELAB
    (specular excluded). γ > 1 compensates the white card showing through
    transparent drawdowns (γ up to ~3.1); 11 paints where the two Golden
    datasets disagree (ΔE > 8, likely formulation changes) keep an
    uncalibrated fallback. Whites are fitted with the finite-thickness K-M
    film equation from their thin/opaque L* pair (zinc s_rel ≈ 0.42).
  - *K-M 2-constant*: scattering-weighted pseudo two-constant with
    opacity-class weights; thin-film endpoints. Comparison mode.
  - *K-M 1-constant*: classic `(K/S)_mix = Σ cᵢ(K/S)ᵢ`; thin-film endpoints.
  - *Geometric mean*: Burns' weighted geometric mean of reflectance.
- **Colour pipeline**: reflectance → XYZ via CIE 1964 10° CMFs × D65
  (self-consistent white point) → CIELAB → sRGB. Reproduces Golden's own
  published Lab values for all 78 masstones at mean ΔE76 **0.037**
  (the previous 20 nm / 2°-observer chain measured mean 3.34, max 13.75).
- **Solver**: deterministic — every 1–N-paint subset of the ~15 most relevant
  pigments is optimised with Nelder–Mead in softmax space against a CIEDE2000
  objective, with a small complexity penalty favouring simpler recipes; trace
  components are dropped and the recipe re-optimised so what you see is
  exactly what was evaluated. Results also include a practical
  parts ratio (e.g. `13 : 2 : 1`) and a D65→A colour-inconstancy index.
- **Target**: converted sRGB → Lab directly; the chart's target line is the
  *smoothest metamer* — the smoothest physical reflectance with exactly the
  target's colour.

See [`services/physicsEngine.ts`](services/physicsEngine.ts) and
[`services/colorimetry.ts`](services/colorimetry.ts) for the maths, and
`npx tsx scripts/validate.ts` for the validation harness (Sharma ΔE2000
reference pairs, masstone reproduction, tint physics, solver round-trips,
determinism).

> **Note on Golden's own MXR mixer**: Golden's virtual mixer is a proprietary
> server-side engine ("PaintEngine™", PaintLife Pty Ltd) built from ~2 000
> physical mixes — its algorithm is not public, so this app is an open
> re-implementation grounded in Golden's published dataset rather than a
> clone. Lineage: justpaint.org's Virtual Paint Mixer article and
> realtimerendering.com/golden.html.

## Run

**Prerequisites**

- [Node.js](https://nodejs.org/) 18+
- [Rust toolchain](https://rustup.rs/) (only if you want the Tauri desktop
  shell or installers — the web version works without Rust)

**Web (browser, hot reload)**

```sh
npm install
npm run dev
```

Open http://localhost:3050/.

**Desktop (Tauri)**

```sh
npm run tauri:dev       # native window, hot reload
npm run tauri:build     # produces an installer under src-tauri/target/release/bundle/
```

## Cutting a release

Cross-platform installers are built on GitHub Actions
([`.github/workflows/release.yml`](.github/workflows/release.yml)).

```sh
# bump version in package.json and src-tauri/tauri.conf.json, then:
git tag v0.1.0
git push origin v0.1.0
```

Pushing the tag kicks off a matrix build on Windows, macOS
(universal — Intel + Apple Silicon), and Ubuntu 22.04, and publishes a draft
Release with the `.msi` / `.exe` / `.dmg` / `.deb` / `.AppImage` attached.
Review the draft under the repo's **Releases** tab and click **Publish** to
make it public.

## Project layout

```
App.tsx                 # top-level layout & state
components/             # React UI
  ColorPicker.tsx       # hex, native colour input, screen picker (EyeDropper API), image sampler
  PaletteManager.tsx    # pigment toggles + max-pigments stepper
  RecipeDisplay.tsx     # results panel
  SpectralChart.tsx     # target vs. mixture reflectance
services/
  physicsEngine.ts      # Saunderson + K-M mixing models + deterministic solver
  colorimetry.ts        # CIE 1964 10° / D65 tables, Lab, sRGB bridge, ΔE2000
utils/colorUtils.ts     # thin wrappers over services/colorimetry.ts
constants.ts            # pigment list + 10 nm reflectance + scattering weights
scripts/
  validate.ts           # validation harness (npx tsx scripts/validate.ts)
  golden_lab_fixture.json  # Golden's published Lab per paint
src-tauri/              # Rust shell for desktop builds
generate_constants.py   # regenerates constants.ts from the Golden spreadsheet
```
